Each band joins the same prompts under two conditions. Its thickness is the number of prompts with that outcome. Thin lines subdivide each band in groups of eight prompts. The gap separates correct and incorrect answers at each end. The curves connect the two measurements. Only the endpoints were measured.

Each model received 72 questions in three equally sized task groups, each with the correct value assigned to A and to B. The selected layout determines which letter is printed first. The letter score uses the model’s most likely next token. Each steered model used its own direction learned on 48 separate training questions.
