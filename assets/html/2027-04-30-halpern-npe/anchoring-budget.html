Illustration of guarantees, not measured algorithm trajectories. D = L₂ = 1; constants and accuracy-dependent logarithms in the inner solver cost are suppressed. The two displayed sequences have the same square-sum budget, ΣRₜ² = 1.

The PPA sequence Rₜ = 1/√T saturates Cauchy–Schwarz at the selected finite horizon. It is a compatible witness for what the square-sum bound alone permits, not a claim that PPA always follows this sequence. The Halpern sequence is a normalized 1/(t+1) profile.

The final curves are normalized bound proxies: PPA’s ergodic gap and Halpern’s proximal residual are different criteria. This is a comparison of the budget argument and exponents, not a direct numerical error comparison.

The argument behind the animation

Let Rₜ = ‖xₜ − Pη(xₜ)‖. In the cost model used in the blog paragraph, the aggregate second-order subproblem cost is proportional to ηL₂ΣRₜ, up to suppressed factors.

PPA: ΣRₜ² ≤ D² implies ΣRₜ ≤ D√T. Keeping ηL₂ΣRₜ = O(T) gives η = O(√T/(L₂D)), and the gap bound O(D²/(ηT)) has the classical T−3/2 exponent.

Halpern: Rₜ ≤ CD/(t+1) implies ΣRₜ ≤ CDHT = O(D log T). An explicit O(T) inner budget permits η of order T/(L₂D log T), yielding a residual bound with log T / T² scaling. Alternatively, η of order T/(L₂D) costs O(T log T), which is still Õ(T). Expressed in total oracle calls, this gives the Õ(N−2) exponent.

For general p, the blog’s high-order inner analysis is needed; the displayed linear cost ηL₂Rₜ applies to this p = 2 explanation.
